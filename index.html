Privacy Policy

Effective Date: October 22, 2026 • Developer: Nathan Béliveau

This Privacy Policy explains how DashBot collects, processes, and protects data when operating on Discord.

1. Data We Process

To deliver its features, the App processes minimal data provided via the official Discord API, including:

    >Discord Identifiers (IDs): User IDs, Server (Guild) IDs, and Channel IDs to manage tickets and server configurations.
  • Message Content: Processed in real-time strictly for auto-moderation filtering and support ticket channel routing.

Processed data is used solely to:
