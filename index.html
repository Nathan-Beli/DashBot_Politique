Politique de Confidentialité (Privacy Policy)

Effective Date: October 22, 2026

1. Introduction

This Privacy Policy explains how Nathan Béliveau ("we", "us", or "our") handles data in connection with the DashBot application ("the App") on Discord. By adding or using the App, you agree to the processing of information in accordance with this policy.

2. Information We Process

To function properly, the App processes minimal data provided via the Discord API, which may include:

  • Discord User IDs and Usernames: Required to manage support tickets and moderation logs.
  • Server/Guild IDs and Channel IDs: Required to store server-specific configurations and permissions.
  • Message Content: Processed in real-time strictly for auto-moderation filters and ticket channel management.

3. How We Use Your Information

We use the collected information solely to :

  • Provide support ticket services within your Discord server.
  • Execute auto-moderation rules configured by server administrators.
  • Save server configuration settings.

4. Data Sharing and Security

We do not sell, trade, or rent any user data to third parties. All data processed relies on Discord's secure infrastructure.

5. Data Retention & Deletion

Server administrators can request the deletion of their stored configuration data or ticket logs at any time by removing the bot from their server or by contacting us directly.
