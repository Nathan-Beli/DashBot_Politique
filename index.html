Politique de Confidentialité

Date d'effet : 22 octobre 2026 • Développeur : Nathan Béliveau

La présente Politique de Confidentialité explique comment DashBot collecte, utilise et protège les données lors de son fonctionnement sur la plateforme Discord.

1. Données collectées

Pour fonctionner correctement, le Bot traite uniquement les informations minimales nécessaires fournies via l'API officielle de Discord :

  • Identifiants Discord (IDs) : ID d'utilisateur, ID de serveur (Guild ID) et ID de salon afin de gérer les configurations et les tickets.
  • Contenu des messages : Traité temporairement pour l'auto-modération (détection de liens interdits/spam) et pour la création de tickets de support.

2. Utilisation des données

Les données collectées sont strictement utilisées pour :

  • Assurer le fonctionnement du système de support par ticket.
  • Appliquer les règles d'auto-modération configurées par les administrateurs du serveur.
  • Conserver les paramètres de configuration propres à chaque serveur.

3. Partage et Stockage des données

  • Aucune vente : Vos données ne sont jamais vendues, louées ou cédées à des tiers.
  • Sécurité : Les données sont conservées de manière sécurisée et restreinte.

4. Conservation et Suppression

Les données de configuration sont conservées tant que le Bot est présent sur votre serveur. Si le Bot est retiré du serveur, les administrateurs peuvent contacter le développeur pour demander la suppression complète des données enregistrées.

5. Protection des mineurs

Conformément aux règles de Discord, l'utilisation de DashBot est réservée aux personnes âgées d'au moins 13 ans (ou l'âge légal dans votre pays).

6. Contact & Droits

Si vous souhaitez consulter, modifier ou demander la suppression des données enregistrées concernant votre serveur, contactez :
Nathan Béliveau — nathan.beliveau@outlook.com
